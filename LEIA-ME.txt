3. COMO PUBLICAR (GitHub Pages + dominio proprio)
--------------------------------------------------
DOMINIO OFICIAL: www.luxodefestabrasil.com

Arquivos que devem ficar na RAIZ do repositorio:
  index.html, CNAME, robots.txt, sitemap.xml
  + as pastas logos/ e photos/ (mantendo a estrutura).

Passo a passo:
1. Suba TODO o conteudo do pacote para a raiz do
   repositorio (recomendado: GitHub Desktop). O
   repositorio precisa ser PUBLICO.
2. Settings -> Pages -> Branch: main (pasta /root).
3. Em Settings -> Pages -> Custom domain, confirme que
   esta escrito: www.luxodefestabrasil.com
   (o arquivo CNAME ja traz esse valor; o GitHub costuma
   preencher o campo sozinho ao detectar o arquivo).
4. Marque a opcao "Enforce HTTPS".
5. No painel de DNS do dominio (onde foi registrado),
   crie um registro CNAME:
     Host/Nome: www
     Aponta para: SEU-USUARIO.github.io
   Para o dominio sem www redirecionar ao www, crie os
   registros A do apex (luxodefestabrasil.com) com os
   IPs do GitHub Pages:
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
6. A propagacao do DNS pode levar de minutos a 24h.
   Depois, o site abre em https://www.luxodefestabrasil.com

- Apos cada novo envio, o site republica sozinho em
  1-2 minutos. Use Ctrl+Shift+R (ou Cmd+Shift+R) para ver
  a versao nova.
- Apos a 1a publicacao, validar o compartilhamento no
  Facebook Sharing Debugger para atualizar o preview do link.
